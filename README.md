# Dream-Website
Project Presentation: Dream Website (Site dos Sonhos)
The Dream Website is a site that runs directly on the web like a browser, it is a web site. It is relatively simple, but it has some interesting features that I would like to bring. I made it to complete a challenge from Star Dance Hack Club, to complete the web challenge 1, because I want to unlock the web challenge 2.



Features of the Site
About its features, it has three, actually it has five features, six actually. Where on the left side there is the calendar, you can see the day, the month and the year, the stopwatch for you to time study hours or something you prefer. It has the option to start, stop and clear, and it has a painting screen, where you can use your imagination, dream, you can write anything, draw and an option to clear the drawing. In the future I intend to add more colors and other things. There is an option for the search bar, the search bar you can type and you will be directed to three links: YouTube, Google and GitHub. And on the right side there is a notepad for you to save your notes, among other things. And the mini game, which is a small game that I put where you press the space key and go gaining points.
